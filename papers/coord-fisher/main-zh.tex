\begin{abstract}
去中心化传感网络经常面临“最后一英里”协调问题：每个 mote 或边缘智能体只观测到局部读数与局部坐标，但团队必须决定\emph{谁与谁交换什么}，以及在不确定时何时\emph{隔离（quarantine）}报告。感知——由读数与几何诱导的局部范畴分布——与协调——把联合压缩为交换或隔离动作的确定性规则——往往被分开设计。尽管 Dec-POMDP 主动感知与信息驱动传感仔细处理了观察什么，协调层却经常是启发式的，并仅以任务奖励或吞吐量评估。本文提出一个互补问题：\emph{在智能体局部律固定的前提下，哪些与 $\theta$ 无关的协调规则对全局场或事件参数销毁的 Fisher 信息最少？}

我们将协调形式化为 AggregationMap $A=f(Z)$，并用声明乘积联合与其推前之间的数据处理间隙 $I_Z(\theta)-I_A(\theta)\succeq 0$ 量化信息损失。规则按 $\mathrm{tr}(\Delta)=\mathrm{tr}(I_Z-I_A)$ 排序。主要应用是去中心化传感网络。在合成 unit-disk 二维场（$9$ 个 mote）上，核心排序成立且 quarantine-wider 是损失最低的非平凡规则；在 $12$ 个 mote 的 Intel Berkeley Lab（IBRL）真实数据对照上，核心排序同样成立，但两条 quarantine 规则的损失都高于 baseline，因此 quarantine 安全阀要付出信息代价，完整排序取决于数据。在固定传感器的 IMAS$^2$ 网格世界基准上，融合规则的 Fisher 损失排序与条件熵和准确率一致，而 Fisher~$\Delta I$ 被证明是弱的传感器布置准则。无重校准的跨床 AggregationMap 排序迁移在六个有向对的多数上未通过 Heath 的通用与正向提升准则（第~\ref{sec:cross-bed}~节），因此证据只支持床内审计。作为同一 AggregationMap 纲领的可复现解析说明，我们还使用 Jevometry 三智能体数据清洗委员会（适用性、修复、风险），在证据与歧义网格上比较七条纯规则——baseline、stricter、wider、quarantine-to-review、混合 quarantine-wider 拆分、粗粒度二元规则，以及近恒等上界。在设计中心点，baseline 协调约丢弃 $\mathrm{tr}(I_Z)$ 的一半；将 quarantine 软化为人工复核可挽回该损失的相当一部分；再与不同的 auto-normalize/auto-impute 标签组合，可在完整设计网格上进一步改进。排序
$\mathrm{near\text{-}identity}\le\mathrm{wider}\le\mathrm{baseline}
\le\mathrm{stricter}$
在每个网格单元上稳定。我们讨论传感智能体交换与隔离策略的设计含义、迫使确定性映射的 API 约束，以及清洗数值作为与 unit-disk 和 IBRL 结果并列的解析说明的角色。配套代码与可复现表格随 Jevometry 仓库一并提供。
\end{abstract}

\section{引言}

现代传感栈使每个 mote 或边缘智能体廉价地发出看起来已校准的局部判断范畴分布：观测质量、是否上报、与哪个邻居交换，或读数是否应被隔离。在去中心化传感网络中，这些局部判断很少是最终产物。协调器——往往是团队共享的一小段确定性逻辑——把智能体输出的联合压缩为交换决策（谁/交换什么）或隔离安全阀~\citep{jevometry2026}。

这种压缩是信息瓶颈。经典决策理论与 Dec-POMDP 规划优化定义在信念或预测质量上的奖励~\citep{lauri2020prediction,lauri2020decpomdp,oliehoek2016decpomdp}。信息论多智能体感知最大化互信息或相关集函数，常带有子模贪婪保证~\citep{krause2008near,nemhauser1978analysis,corah2021scalable,shi2026imas2}。这些工作选择\emph{观察什么}或\emph{谁应观察}。它们本身并不能告诉实践者：两条已部署的协调规则中，哪一条对网络设计所跟踪的全局场或事件参数~$\theta$ 保留更多敏感性。

Fisher 信息为这种敏感性提供了局部、可微的语言~\citep{fisher1925theory,amari2016information}。对具有得分 Jacobian $J_Z$ 的离散模型 $P_\theta(Z)$，Fisher 矩阵 $I_Z=J_Z^\top \mathrm{diag}(P_\theta)^{-1} J_Z$ 度量无穷小参数移动如何强烈改变结果分布。当固定映射 $f$ 产生动作 $A=f(Z)$ 时，Fisher 信息的数据处理不等式在标准正则条件下断言 $I_Z-I_A\succeq 0$~\citep{zamir1998fisherdpi,cover2006elements}。当 $I_Z$ 固定时，标量 $\mathrm{tr}(I_Z-I_A)$ 便是可比较的损失摘要。

\paragraph{目标设定与当前证据。}
我们的主叙事是：在局部观测下的去中心化传感智能体，以 Fisher~$\Delta I$ 作为共享决策函数，在协调规则——包括不确定时的隔离——之间进行选择。主实验是合成 unit-disk 二维场；次要对照是 $12$ 个 mote 的 Intel Berkeley Lab（IBRL）子网。二者均在第~\ref{sec:sensor-results}~节报告。我们另外报告同一 AggregationMap 纲领的可复现解析实例：Jevometry 三智能体清洗委员会，其表格与图作为按 $\mathrm{tr}(\Delta)$ 对
\texttt{near}/\texttt{wider}/\texttt{baseline}/\texttt{stricter}/
\texttt{quarantine\_*}/\texttt{near\_identity} 类规则排序的概念验证。

\paragraph{贡献。}
\begin{enumerate}
  \item 我们将多智能体协调规则比较表述为：在共享声明联合下，按 Fisher 信息损失对与 $\theta$ 无关的聚合映射排序，并以传感网络交换与隔离作为动机性的 AggregationMap 语义（第~\ref{sec:problem}~节）。
  \item 我们将该纲领映射到三层——全局场参数 $\theta$、局部智能体范畴律，以及与 $\theta$ 无关的 AggregationMap——并运行合成 unit-disk 主实验与 IBRL 真实数据对照（第~\ref{sec:sensor-layers}~节与第~\ref{sec:sensor-results}~节）。核心排序在二者上都成立；quarantine-wider 在 unit-disk 上最好（$1.784$），而在 IBRL 上两条 quarantine 规则的损失都高于 baseline（$3.042$、$3.101$，对比 $2.785$）。
  \item 在固定传感器的 IMAS$^2$ 网格世界上，融合规则的 $\mathrm{tr}\Delta I$ 排序与条件熵的 Spearman 相关为 $0.65$--$0.93$，与负准确率为 $0.51$--$0.87$；作为传感器布置准则，Fisher~$\Delta I$ 较弱且在随机运动下失效，我们如实作为负面发现报告（第~\ref{sec:imas2-grid}~节）。
  \item 在 unit-disk、IBRL 与 IMAS$^2$ 之间无重校准的跨床迁移作为边界失败：通用 $2/6$，正向提升 $0/6$，S1 $0/6$，S2 $3/6$；优先方向 unit-disk$\to$IMAS$^2$ 与 IMAS$^2\to$IBRL 均失败（第~\ref{sec:cross-bed}~节）。
  \item 作为当前解析实例，我们在 Jevometry 清洗委员会中实例化七条纯规则，并提供可复现实验装置：扫描参数网格、导出 CSV/JSON（含参数轴损失对角元与分数损失），并生成发表用图（第~\ref{sec:method}~节）。
  \item 经验上，在设计中心点 baseline 规则约损失 $\mathrm{tr}(I_Z)$ 的 $44\%$；quarantine-to-review 相对 baseline 约削减四分之一损失；混合 quarantine-wider 规则进一步改进（$\mathrm{tr}(\Delta)\approx 2.16$）并在完整网格上优于 quarantine-to-review；二元闸门的损失高于更严的中风险拒绝（第~\ref{sec:experiments}~节）。这些数值用于解析地说明 AggregationMap 审计；传感结果见第~\ref{sec:sensor-results}~节。
  \item 我们讨论该度量如何补充以奖励为中心的 Dec-POMDP 传感协调评估，以及 API 约束（仅确定性映射）对未来可学习协调器的含义（第~\ref{sec:discussion}~节）。
\end{enumerate}

本稿旨在作为伴随开源实验的短期刊 / arXiv 草稿。清洗委员会数值是解析且示意性的；unit-disk 与 IBRL 传感结果是主要经验叙事。

\section{相关工作}
\label{sec:related}

\paragraph{Dec-POMDP 主动感知。}
\citet{lauri2020prediction} 通过个体预测动作，将带预测奖励的多智能体主动感知约化为标准 Dec-POMDP 求解器，并给出去中心化损失界。\citet{lauri2020decpomdp} 在离散与连续状态设定下，用策略图改进优化凸信念依赖奖励（例如负熵）。两条线通常把团队视为固定，并把信息目标折入奖励，而非事后比较确定性协调器。

\paragraph{信息驱动的多智能体感知。}
子模传感器选择与多机器人跟踪在单调性下以贪婪 $(1-1/e)$ 保证最大化互信息或相关覆盖目标~\citep{krause2008near,corah2021scalable}。\citet{olkin2024vulcan} 与 \citet{molloy2023smoother} 进一步将规划连接到信息与平滑器熵。

\paragraph{IMAS$^2$（最接近的 Dec-POMDP 亲戚）。}
\citet{shi2026imas2} 研究 Dec-POMDP 中传感智能体选择与去中心化主动感知策略综合的\emph{联合}问题（\texttt{arXiv:2510.20009}；AAMAS~2026）。内层以潜在轨迹（或秘密属性）与团队部分观测之间的互信息为统一目标优化感知策略；外层在子模性下贪婪选择智能体，并在其给出的相继边际收益比条件下给出 $(1-1/e)$ 风格保证。实验为网格世界中的多智能体协同感知。该路线\emph{优化谁去感知以及如何感知}。我们的路线相关但不同：\emph{固定}局部智能体律，按动作聚合后的 Fisher 信息损失 $\Delta_f=I_Z-I_A$ 对与 $\theta$ 无关的 AggregationMap 排序——并以 quarantine 作为确定性安全阀——而不是通过子模智能体选择去最大化互信息。两种度量回答互补问题（选择/综合传感器 vs.\ 审计最后一英里协调）。

\paragraph{面向智能体的信息几何。}
Fisher--Rao 几何为参数化分布族提供局部度量~\citep{amari2016information}。Jevometry 为智能体系统操作化节点级与系统级 Fisher 诊断~\citep{jevometry2026}。我们使用其推前 \texttt{information\_loss} 原语，且不修改底层 DECLARED\_PRODUCT 构造。

\section{问题形式化}
\label{sec:problem}

\subsection{声明乘积联合}

令 $\theta\in\Theta\subset\mathbb{R}^d$ 参数化多智能体系统。每个智能体 $i\in\{1,\ldots,m\}$ 在有限局部字母表 $\mathcal{Z}_i$ 上发出范畴分布 $P_\theta(Z_i)$。\emph{声明乘积联合}断言给定 $\theta$ 时的条件独立：
\begin{equation}
  P_\theta(Z=z)=\prod_{i=1}^{m} P_\theta(Z_i=z_i),
  \qquad z=(z_1,\ldots,z_m)\in\mathcal{Z}=\prod_i\mathcal{Z}_i.
\end{equation}
在下文的清洗实例中，$m=3$，$d=2$，且 $\theta=(\mathrm{evidence},\mathrm{ambiguity})$，坐标在 $[0,1]$。在计划中的传感实例中，$\theta$ 转而表示全局场或事件参数（例如源位置、强度或事件指示），而非原始单节点读数。乘积声明是模型假设，而非关于在线 API 或无线电轨迹的经验主张。

\subsection{作为聚合的协调}

\begin{definition}[协调规则]
协调规则是映射 $f:\mathcal{Z}\to\mathcal{A}$，映入有限动作字母表 $\mathcal{A}$。若 $f$ 仅是联合结果的全函数（无隐随机性），则称其为\emph{纯}的；若 $f$ 不依赖 $\theta$，则称其为\emph{与 $\theta$ 无关}的。
\end{definition}

诱导的动作律是推前
\begin{equation}
  P_\theta(A=a)=\sum_{z:f(z)=a} P_\theta(Z=z).
\end{equation}
若 $J_Z(\theta)$ 是联合概率向量关于 $\theta$ 的 Jacobian，则聚合 Jacobian $J_A$ 通过对共享同一动作标签的 $J_Z$ 行求和得到。

\subsection{Fisher 信息损失}

\begin{definition}[规则的信息损失]
对与 $\theta$ 无关的规则 $f$，定义
\begin{align}
  I_Z(\theta) &= J_Z(\theta)^\top \mathrm{diag}\bigl(P_\theta(Z)\bigr)^{-1} J_Z(\theta),\\
  I_A(\theta) &= J_A(\theta)^\top \mathrm{diag}\bigl(P_\theta(A)\bigr)^{-1} J_A(\theta),\\
  \Delta_f(\theta) &= I_Z(\theta)-I_A(\theta).
\end{align}
我们报告 $\mathrm{tr}(I_Z)$、$\mathrm{tr}(I_A)$ 与 $\mathrm{tr}(\Delta_f)$ 作为标量摘要，并数值验证 $\Delta_f\succeq 0$（PSD 检查）作为数据处理诊断。
\end{definition}

\begin{proposition}[固定映射的 DPI]
在标准正性与可微条件下，任意与 $\theta$ 无关的 $f$ 满足 $\Delta_f(\theta)\succeq 0$。当 $f$ 在 $P_\theta$ 的支撑上单射时等号成立。
\end{proposition}

\begin{remark}
依赖 $\theta$ 的映射（软策略、以参数为条件的学习路由）落在 Jevometry 实现的该保证之外，并被报告为不支持。因此本文仅关注纯的、全覆盖的、与 $\theta$ 无关的规则——即匹配典型生产 if-then 协调器、mote 固件交换策略与库的 AggregationMap 契约的那一类。
\end{remark}

\paragraph{比较原则。}
固定智能体与联合构造。按 $\mathrm{tr}(\Delta_f)$ 对规则排序（越低越好），或等价地按 $\mathrm{tr}(I_A)$（越高越好）。因为 $I_Z$ 共享，按损失排序与按保留信息排序相同。

\section{传感智能体协调的三层结构}
\label{sec:sensor-layers}

AggregationMap 纲领可用匹配去中心化传感的三层解读：

\begin{enumerate}
  \item[(i)] \textbf{全局参数 $\theta$。}
  $\theta$ 表示感兴趣的场级或事件级量（源位置、强度、空间协方差超参数、二元事件指示），\emph{而非}单个 mote 的原始标量读数。Fisher 损失相对于该 $\theta$ 度量。

  \item[(ii)] \textbf{局部智能体律。}
  每个传感器是一个智能体。其范畴分布 $P_\theta(Z_i)$ 由局部坐标与局部读数诱导——例如观测质量分箱、上报/保持决策，或 unit-disk 通信图下的邻居选择字母表。声明乘积联合组装这些局部律。

  \item[(iii)] \textbf{作为交换与隔离的 AggregationMap。}
  与 $\theta$ 无关的规则 $f$ 把联合压缩为协调动作：谁与谁交换、发送何种载荷，或在局部不确定性高时是否隔离报告。候选族复用下文研究的同一类定性旋钮——近邻交换、更宽邻域、baseline 固件、更严阈值、隔离变体，以及近恒等上界——并按 $\mathrm{tr}(\Delta_f)=\mathrm{tr}(I_Z-I_A)$ 排序。
\end{enumerate}

\paragraph{传感实验。}
\begin{itemize}
  \item \textbf{主实验：}二维场中的合成 unit-disk 传感器（$9$ 个 mote，$3\times3$ 网格，$R=0.45$）。局部字母表与 AggregationMap 遵循第~(ii)--(iii)~层；结果见表~\ref{tab:unitdisk}。
  \item \textbf{对照：}$12$ 个 mote（编号 4, 11, 16, 18, 20, 26, 34, 39, 42, 47, 50, 53）的 Intel Berkeley Lab（IBRL）子网，作为同一 AggregationMap 接口下的真实部署健全性检查；结果见表~\ref{tab:ibrl}。
\end{itemize}
第~\ref{sec:method}--\ref{sec:experiments}~节中的清洗委员会研究，是层~(i)--(iii) 的当前、完全可复现解析说明，其中 $\theta=(\mathrm{evidence},\mathrm{ambiguity})$，修复/隔离动作扮演交换/隔离语义的角色。

\section{方法与实验设计}
\label{sec:method}

\subsection{三智能体清洗委员会
（解析实例）}

我们复用离线 Jevometry 教程 \texttt{examples/three\_agent\_cleaning}~\citep{jevometry2026} 作为 AggregationMap 审计的概念验证——而非关于在线传感场的主张。三个解析 softmax 智能体为噪声数值字段的单个候选修复产生分布：

\begin{center}
\begin{tabular}{lll}
\toprule
智能体 & 原语 & 支撑 \\
\midrule
applicability & Noul & $\{\mathrm{false},\mathrm{true}\}$ \\
repair & Choice & $\{\mathrm{normalize},\mathrm{impute},\mathrm{quarantine}\}$ \\
risk & Score & $\{0,1,2\}$（低/中/高） \\
\bottomrule
\end{tabular}
\end{center}

局部 logit 在设计中心 $\theta_0=(0.7,0.3)$ 附近对 $(\theta-\theta_0)$ 为仿射，概率由 softmax 得到。联合是声明乘积（ConstructionMode.DECLARED\_PRODUCT）。不查询任何在线 API；不执行实际数据库写入。该委员会中的 quarantine 与传感隔离阀扮演相同的结构角色：一种合并可区分联合结果的粗动作，因此除非被软化（例如变为人工复核或延迟交换），否则会抬高 $\mathrm{tr}(\Delta_f)$。

\subsection{协调规则}
\label{sec:rules}

我们比较七条规则，均为纯且与 $\theta$ 无关：

\begin{description}
  \item[baseline] 若不适用、quarantine 或高风险则拒绝；若 normalize 且低风险则自动应用；否则人工复核。
  \item[stricter] 同 baseline，但中风险也拒绝。
  \item[wider] 拒绝条件同 baseline；低风险 normalize 与 impute 成为不同的自动标签（\texttt{auto\_normalize}、\texttt{auto\_impute}）。
  \item[quarantine\_review] Quarantine 路由到人工复核而非拒绝；仅在不适用或高风险时拒绝。
  \item[quarantine\_wider] Quarantine-to-review 与 wider 的双自动标签组合：本研究中经验上最强的粗策略。
  \item[coarse\_binary] 在 baseline 拒绝条件下拒绝；否则为单一 \texttt{proceed} 动作（自动应用与复核合并）。
  \item[near\_identity] 每个联合结果元组一个动作标签（18 个标签）：在该字母表下的 Fisher 保留上界。
\end{description}

用传感语言表述，baseline/stricter/wider 对应更窄或更宽的交换策略与风险阈值；隔离变体是安全阀；近恒等是信息保留上界，而非可部署的无线电调度。

\paragraph{IMAS$^2$ 基线。}
我们以缩减形式重跑了上游 IMAS$^2$ 训练：每传感器 $150$ 次迭代（论文为 $1000$），按报告的传感器顺序，共耗时 $2051$\,s；五个传感器后的训练熵为 $0.558$。另外，\citet{shi2026imas2} 报告 IMAS$^2$ 在其随机、大范围设置下的条件熵为 $0.493$、准确率为 $86.0\%$。这些报告数值与我们的缩减重跑不可直接比较（迭代预算、范围与评估器均不同）。完整流程在 CPU 上估计需超过 $12$ 小时，未运行。

\section{跨床 AggregationMap 迁移：失败的边界}
\label{sec:cross-bed}

\paragraph{协议。}
我们检验在一张床上学到的 Fisher-$\Delta I$ 排序能否\emph{无需重校准}迁移到另一张床。三张床为合成 unit-disk 场、IBRL 对照，以及 IMAS$^2$ 网格世界（固定朝向、随机动态、小范围）。同一组七个 AggregationMap 在每张床上打分。unit-disk 与 IBRL 的逐床效用取自
\texttt{unit\_disk\_rule\_utility.csv} /
\texttt{ibrl\_rule\_utility.csv}：在 $\theta_{\mathrm{centre}}$ 处声明联合下的二元 $y_{\mathrm{share}}$，以及精确贝叶斯条件熵 $H$ 与准确率。IMAS$^2$ 效用是经既有 HMM 滤波器得到的对抗类型 $\tau$；因此其定义与 $y_{\mathrm{share}}$ 效用不同，我们将三张床视为\emph{不同的}打分域。Heath 的迁移准则施加于全部六个有向对：
\emph{通用}要求
$\rho(\mathrm{src}\,\Delta I,\mathrm{tgt}\,\Delta I)\ge 0.5$、
$\rho(\mathrm{src}\,\Delta I,\mathrm{tgt}\,H)\ge 0.5$ 与
$\rho(\mathrm{src}\,\Delta I,-\mathrm{tgt}\,\mathrm{acc})\ge 0.5$；
\emph{正向提升}要求源床 Fisher pick（排除 \texttt{near\_identity}）在目标床上的准确率超过 baseline，\emph{且} quarantine 按准确率与按 $H$ 均落在下半；
S1/S2 为相应的置换与无矛盾检查；S3 为第~\ref{sec:imas2-grid}~节中已经失败的布置负对照。

\paragraph{结果：边界失败。}
总体而言，通用在 $2/6$ 对上通过，正向提升 $0/6$，S1 $0/6$，S2 $3/6$；S3 仍然失败（表~\ref{tab:cross-bed}）。$\Delta I$ 对 $\Delta I$ 的排序有一定迁移性（六个方向上 $\rho=0.71$--$0.79$），但 Heath 的通用要求三项 Spearman 全部达标，多数因 $\Delta I$--$H$ 或 $\Delta I$--准确率不足而失败。正向提升从未成立：以 unit-disk 为源时经常选出 \texttt{quarantine\_wider}，它在目标床上不如 baseline（例如在 IMAS$^2$ 上为 $0.736$ 对 $0.770$；在 IBRL 上为 $0.907$ 对 $1.000$），且 quarantine 并非跨床稳定地最差。两个优先方向——unit-disk$\to$IMAS$^2$ 与 IMAS$^2\to$IBRL——均失败。仅 \texttt{ibrl}$\to$\texttt{imas2} 与 \texttt{ibrl}$\to$\texttt{unit\_disk} 通过通用，且二者均无正向提升。S1 在每一对上都失败，通常是因为 $n=7$ 条规则产生并列以及不显著的置换 $p$ 值。

\paragraph{定位。}
这是失败的边界，不是软性免责声明。本文证据只支持\emph{床内} AggregationMap 审计。我们不声称跨床通用性：在一张床上有用的 Fisher 排序，在无重校准的情况下并不能选出在另一张床上提升效用的规则，且 quarantine 的排序仍然取决于床。

\section{讨论}
\label{sec:discussion}

\paragraph{传感网络解读。}
在层~(i)--(iii) 下，当局部智能体律固定时，$\mathrm{tr}(\Delta_f)$ 是在交换与隔离规则之间选择的共享离线评分。更软的隔离（延迟或人工/操作员复核而非硬丢弃）与更细的交换字母表（不同的邻居或载荷标签）是表~\ref{tab:center} 中 quarantine-wider 收益的直接类比。二元 proceed/reject 闸门在运维上仍然方便，但在信息上昂贵。传感结果对此有所修正：quarantine-wider 在 unit-disk 上最好，但在 IBRL 上两条 quarantine 规则的损失都高于 baseline（第~\ref{sec:sensor-results}~节）。排序机制与 DPI 证书可跨场景迁移；绝对迹以及 quarantine 在排序中的位置不能迁移。

\paragraph{“一半 Fisher”意味着什么。}
Baseline 协调后 $\mathrm{tr}(I_Z)$ 下降 $44\%$ 并不意味着系统“错了” $44\%$。它意味着：局部上，参数的无穷小变化对最终动作分布的推动，弱于对智能体输出联合的推动。若监控仪表盘只看动作或交换率，就会低估底层智能体的敏感性。若下游估计器试图从动作反推 $\theta$，其问题严格难于从 $Z$ 反推。

\paragraph{设计要点。}
在清洗说明中可实现的三/四动作策略里，将 quarantine 路由到复核比单独的 baseline 或 wider 保留更多 Fisher；将该软化与不同的 auto-normalize/auto-impute 标签组合，在本网格上仍严格更好。实践者在 A/B 测试或固件刷写前讨论规则变更时，可将 $\mathrm{tr}(\Delta_f)$——以及需要时其参数轴对角元——当作廉价的离线评分。

\paragraph{与 Dec-POMDP 奖励及 IMAS$^2$ 的关系。}
预测奖励与负熵目标~\citep{lauri2020prediction,lauri2020decpomdp} 优化感知策略。IMAS$^2$~\citep{shi2026imas2} 进一步在 Dec-POMDP 动力学与子模贪婪选择下，把智能体选择与最大化互信息的感知策略耦合。我们的度量并不取代这些方案；它在感知（以及任何选择）固定之后，审计\emph{最后}一道确定性压缩。选择扩展谁可以观察；Fisher $\Delta_f$ 排序追问这些观察在选定的 AggregationMap——含 quarantine——下，有多少在交换层幸存。

\paragraph{API 约束。}
许多智能体与 mote 平台仅暴露采样结果加确定性业务或固件规则。软的、依赖 $\theta$ 的路由器要么需要声明条件动作模型，要么拒绝 DPI 证书——正是 Jevometry AggregationMap 所编码的契约。将本研究扩展到随机协调器是未来工作，并需要额外正则性。

\section{局限}
\label{sec:limitations}

\begin{itemize}
  \item 所报告的经验数值来自清洗委员会中手工指定的解析 softmax 族，而非拟合的在线决策模型。绝对迹是示意性的。
  \item 传感实验规模较小：$9$ 个合成 mote，以及单一中心点上 $12$ 个 mote、$480$ 行的 IBRL 子样本。quarantine 的排序在二者之间翻转，因此核心排序之外的排序取决于数据，不应解读为普遍结论。
  \item 在 IMAS$^2$ 网格世界上，$\mathrm{tr}\Delta I$ 对逐步 Fisher 信息求和，忽略了跨步的时间相关性。
  \item 在确定性动态下，滑移导数是在边界 slip $=0$ 处的单侧有限差分。
  \item 重训策略行在我们的评估器中重放记录的状态与动作并重新采样观测；它们与上游训练 rollout 并非完全贝叶斯一致。
  \item 无重校准的跨床迁移在多数对上未通过 Heath 的通用与正向提升准则；$n=7$ 条规则常产生并列，并使 S1 的置换检验不显著。各床的效用定义也不同（unit-disk/IBRL 上的 $y_{\mathrm{share}}$ 对 IMAS$^2$ 上的对抗类型 $\tau$），因此失败的迁移是当前证据的边界，而非关于一切可能共享效用的断言。
  \item 条件独立是声明的，而非检验的。
  \item 我们报告 $\Delta_f$ 的参数轴对角元与特征值，但完整 CRLB 式解读仍需要清洗例子未提供的观测似然契约。
  \item 各规则的动作字母表不同；作为关于 $\theta$ 的保留信息，$\mathrm{tr}(I_A)$ 比较仍然有意义，但把 $|A|$ 当作效用的解释超出范围。
  \item 尚无人工、任务奖励或传感精度研究验证更低的 Fisher 损失会改善清洗或场估计结果。
\end{itemize}

\section{结论}
\label{sec:conclusion}

我们提出在共享声明联合下按 Fisher 信息损失对多智能体协调规则排序，并以去中心化传感智能体交换与隔离作为主要的 AggregationMap 叙事。在局部感知固定时，确定性协调器可丢弃联合 Fisher 迹的很大一部分；小的规则编辑（隔离处理、更细动作字母表、风险或邻域阈值）会以易于离线度量的幅度移动该损失。三智能体清洗委员会提供可复现的解析概念验证——包括稳定排序
$\mathrm{near\text{-}identity}\le\mathrm{wider}\le\mathrm{baseline}
\le\mathrm{stricter}$
以及 quarantine-wider 收益。在传感网络上，核心排序在合成 unit-disk 场与 $12$ 个 mote 的 IBRL 对照上均成立；quarantine-wider 在 unit-disk 上最好，但在 IBRL 上两条 quarantine 规则的损失都高于 baseline，因此 quarantine 安全阀在真实数据上要付出信息代价，完整排序取决于数据。在 IMAS$^2$ 网格世界上，融合规则排序与下游熵和准确率一致，但 Fisher~$\Delta I$ 是弱的传感器布置准则；该方法的角色是审计聚合，而非选择传感器。无重校准的跨床 AggregationMap 迁移作为边界失败——通用大多未通过，正向提升从未成立，优先方向 unit-disk$\to$IMAS$^2$ 与 IMAS$^2\to$IBRL 均失败——因此本文只支持床内规则审计。

未来工作包括：(i)~将 unit-disk 与 IBRL 实验扩展到更多 mote、中心点与时间窗口；(ii)~在适当时用 TypeSafe / 在线决策模型 Jacobian 替换解析智能体；(iii)~带显式条件动作模型的随机协调器；(iv)~在 JAAMAS 风格的经验研究中将 $\mathrm{tr}(\Delta_f)$ 与任务级效用（场估计误差、清洗质量）耦合。
